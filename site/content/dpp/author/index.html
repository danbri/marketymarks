dpp authoring (experimental)

marketymarks / dpp

Fill in a battery passport. The form is generated from the EC's own rules (SHACL shapes, release 1.0.0): it asks for what the rules require for the battery type and view you choose, offers the EC code lists and units, and can check the result. Nothing leaves your browser.

The form follows the EC shapes; the check uses the same rules as the checker. Not an official EC tool.

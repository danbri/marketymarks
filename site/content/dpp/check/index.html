About this work →

Check an EU Digital Product Passport (EC JSON) against the European Commission's own published rules, release 1.0.0: the same SHACL shapes and codelists the DPP Registry uses. Everything runs in your browser; nothing is uploaded. Batteries are covered (EV, industrial, light means of transport), plus the shared core.

How it works: the passport JSON is turned into RDF with the EC's JSON-LD contexts, then validated with the EC's SHACL shapes, merged with the EC's SKOS codelists, using @factoidal/core 0.29.0 (Lean-based, WebAssembly). The self-test feeds it deliberately broken passports that must fail; if any passes, don't trust the results.

Not an official EC tool. EC files © European Union, EUPL-1.2. Factoidal is experimental and unreviewed.

# EU DPP semantic data artifacts, release 1.0.0

This folder is an unmodified copy of the contexts, shapes, vocabularies and
test passports in the European Commission's "DPP Registry – Semantic Data
Artifacts" (release 1.0.0, 30 Oct 2026), published by DG GROW at
https://single-market-economy.ec.europa.eu/single-market/digital-product-passport/resources-documentation_en

- Copyright: European Commission / European Union.
- Licence: the files declare the European Union Public Licence v1.2 (EUPL-1.2),
  https://interoperable-europe.ec.europa.eu/collection/eupl/eupl-text-eupl-12
- The `manifest.json` next to this notice lists every file. It was added here,
  is not part of the EC release, and has no other changes.

The files are kept here because their own web addresses
(`https://repository.product-passport.ec.europa.eu/...`) did not resolve when
checked on 2026-11-03, so the DPP checker cannot load them from the EC.
